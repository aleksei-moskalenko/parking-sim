# Тренажёр парковки

Симулятор парковки от первого лица в браузере: параллельная парковка и заезд
задним ходом в гараж, седан и минивэн, коробка-автомат, 6 уровней сложности
и оценка как на экзамене.

## Запуск

```bash
npm start            # python3 serve.py 8080 — статика без кэширования
```

Откройте http://localhost:8080 — страница начинается с меню: упражнение,
машина, уровень.

## Сборка в один файл

```bash
npm install
npm run build        # → dist/parking-sim.html
```

Получается один HTML (~1.8 МБ): код, three.js, стили и модели внутри, сеть не
нужна — файл можно открыть прямо с диска двойным кликом. Версия three.js в
`package.json` должна совпадать с версией в importmap `index.html`, иначе
сборка остановится с ошибкой.

## Управление

| Клавиша | Действие |
|---|---|
| `W` | газ |
| `S` | тормоз |
| `A` / `D` | руль: медленно поворачивается, сам не возвращается |
| `1` `2` `3` `4` | P / R / N / D (только стоя и с нажатым тормозом) |
| `T` | вид сверху |
| `H` | траектории всех четырёх колёс |
| мышь | смотреть по сторонам; клик — плавно вернуть голову прямо |
| `Esc` | пауза |

В D и R машина сама ползёт, как настоящий автомат. Заезд заканчивается, когда
вы ставите P. Времени нет, но засчитывается каждое касание, наезд на бордюр,
выезд за разметку, расстояние до бордюра больше 30 см, угол больше 3°, а в
гараже — смещение от центра больше 25 см. Если включали подсказки, в
результате будет пометка «С подсказками».

## Тесты

```bash
npm test             # логика: машина, уровни, касания, оценка, ввод
npm run test:levels  # доказательство, что каждый уровень проходим (~3–4 мин)
```

## Устройство

- `src/sim/` — чистая логика без Three.js: кинематика машины, уровни,
  столкновения, оценка, сессия заезда, решатель для проверки уровней.
- `src/view/` — плавный поворот головы и предсказание траекторий колёс.
- `src/render/` — сцена Three.js, кабина, зеркала, подсказки.
- `src/ui/` — HUD и экраны.

## Модели

Машины и конусы — [Kenney Car Kit](https://kenney.nl/assets/car-kit),
лицензия CC0. Если какой-то модели нет, вместо неё рисуется цветная коробка.
